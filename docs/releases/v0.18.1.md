# autonome-pi v0.18.1

- Background Pi agent work has no implicit deadline; explicit workflow deadlines now accept up to 2,147,483,647 ms (`null` disables the deadline for dynamic workflows). Foreground Pi work and shells retain their default bounds.
- Hosted background dynamic/scripted workflows schedule progress reviews only when a cadence is assigned. Cadences up to 2,147,483,647 ms now persist and schedule correctly; omission schedules none. V3 delegation retains its separate default cadence.
- Includes gated recursive-v3 delegation foundations and offline Pi 0.86.0 worker compatibility. Public v3 activation remains off; these changes have not been validated against a live provider/OAuth flow.

Restart Pi after upgrading. Uncommitted successor-repair work is not part of this release.
