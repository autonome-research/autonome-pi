# v0.18.2 — passive progress, no periodic main-agent prompts

## Fix

Removed the visualizer's periodic review scheduler, delivery pump, acknowledgement watchdog and review-related continuation gates. Workflow progress no longer injects recurring instructions into the main conversation or asks the main agent to reason just because a timer elapsed.

Existing `progress-reviews.json` records are untouched and inert, including scheduled, pending and claimed reviews. Idle transitions, restart, historical review markers, explicit cadence metadata and v3's former fallback cannot reactivate them. The host does not load the retired supervision runtime.

Passive footer/dashboard/status-bridge updates, logs, artifacts and on-demand `thread_phase_runs` inspection remain. Durable success/failure completion handoffs still work; cancellation does not auto-continue. Execution timeouts, ownership checks, launch authorization and resume behavior are unchanged.

`progressReviewIntervalMs` is deprecated. Existing input validation and metadata transport remain compatible with saved callers/templates and verified resumes, but cannot schedule reviews. Tool descriptions, prompt guidance and workflow documentation now say to omit it.

## Upgrade

```sh
pi install git:git@github.com:autonome-research/autonome-pi@v0.18.2
```

Replace an older configured package source rather than loading both copies, then **fully restart every Pi host using the package**. Already-running old hosts retain their old scheduler; previously submitted messages and historical session context cannot be retracted. No review-state deletion or migration is needed. Downgrading can restore the old behavior.

This release does not install or integrate `pi-durable`, activate public v3, change dependencies, restore archived successor repair, or update a running installation automatically.
